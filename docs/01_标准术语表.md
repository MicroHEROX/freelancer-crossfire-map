# 01 标准术语表

> 讨论、提交与文档统一使用本表用词。中英对照，按「游戏数据 / 地图表现 / 工具流程」分层。

## 1. 游戏数据层

| 中文 | 英文/原文 | 说明 |
|---|---|---|
| 星系 | star system / system | `universe.ini [system]` 条目，如 `Li01`＝New York（纽约） |
| 星区 | sector | `multiuniverse.ini [sector]`，共 5 个：Sirius、内核、Altair、Canis、Sol |
| 行星系 | planetary system | 游戏内导航图的第三层（星系内部的星球/基地分布）；本项目即「星系图」 |
| 系统文件 | system ini | `DATA\UNIVERSE\SYSTEMS\<星系>\<星系>.ini` |
| 物体 | object | `[Object]`：恒星、行星、基地、空间站、跳跃门/洞、卫星等 |
| 区域 | zone | `[Zone]`：小行星带、冰晶带、碎屑带、雷区、熔岩、气体、星云 |
| 太阳原型 | solar archetype | `DATA\SOLAR\solararch.ini [Solar]`，含 `type`（SUN/PLANET/STATION/JUMP_GATE…）与 `solar_radius` |
| 基地 | base | `universe.ini [Base]`（名称）+ `mbases.ini [MBase]`（阵营）+ `Bases\*.ini [Room]`（设施） |
| 跳跃门 | jump gate | 人工门，`Archetype = jumpgate`，通常双向 |
| 跳跃洞 | jump hole | 自然洞，`Archetype = jumphole`，不稳定，可能单向 |
| 随机跳跃 | random jump | `RandomJumps.ini` 中同一跳跃物体可去多个目标 |
| 贸易航线环 | trade lane ring | `TRADELANE_RING`，按 `prev_ring/next_ring` 链还原为航线并绘制 |
| 导航图 | nav map | 游戏内 F6 地图 |
| 无导航图 | NoNavMap | `NoNavMap.ini` 列出的星系在游戏内导航图不可用 |
| 坐标 | pos | `[Object]`/`[Zone]` 的 `pos = x, y, z`（地图平面为 x–z） |
| 网格缩放 | NavMapScale | `universe.ini [system]` 可选项，地图范围 = 131072 ÷ NavMapScale |
| 网格格位 | grid cell | 8×8 格，列 **A–H**、行 **1–8**，标签在格心 |
| 可见标记 | visit | 0＝隐藏/未标记（如剧情物体），非 0＝已发现 |
| 区域属性位 | property_flags | `[Zone]` 位标志，用于区分小行星带/星云/雷区等（本图按位＋命名分类） |
| 文本编号 | IDS | 32 位文本资源号：高 16 位＝DLL 序号，低 16 位＝字符串 ID |
| 字符串资源 | RT_STRING | PE 资源类型 6，名称与部分信息卡（UTF-16LE） |
| HTML 资源 | RT_HTML | PE 资源类型 23，信息卡（RDL XML） |
| 信息卡格式 | RDL | 游戏信息卡 XML（`<TEXT>/<PARA>/<TRA>`），提取时转 HTML |
| 信息卡 | infocard | 物体/星系/阵营的介绍文本 |
| 阵营 | faction / group | `initialworld.ini [Group]`，如 `li_p_grp`＝自由警察公司 |
| 本地阵营 | local_faction | `mbases.ini [MBase]`，基地所属阵营 |
| 房间 | room | 基地设施：Bar 酒吧 / Trader 商品商 / ShipDealer 飞船商 / Equipment 装备商 |
| 任务变体 | mission variant | MOD 为剧情阶段复制的整份星系（后缀 t/tk/tn/b/c/2 等） |
| 正式版 | final release version | 剧情结束后仍在用的星系版本（本图默认只显示正式版） |
| 开放世界脚本 | openspm*.ini | `DATA\MISSIONS\M**\` 中单机剧情间隙/通关后的状态脚本 |
| 模式变体文件 | `*mp.ini` / `*sp.ini` | 同一星系的多模式版本；单机用基础文件（＝sp 内容） |

## 4. 易混辨析

1. **星系 vs 星区**：星系是单颗恒星系统（`Li01`）；星区是多星系集合（Sirius 星区含 106 条记录）。
2. **行星系**：本项目中指游戏导航图第三层（星系内部图），不是天文学的「行星系统」。
3. **跳跃门 vs 跳跃洞**：门＝人工建造、有隧道动画、通常双向；洞＝自然现象、可能单向/随机。
4. **随机跳跃**：`RandomJumps.ini` 记录的是「同一跳跃物体可去多个目标」，不是独立连接。
5. **ids_name vs strid_name**：都是 IDS 编号；`[Object]`/`[Zone]` 用 `ids_name`，`[System]`/`[Base]` 用 `strid_name`。
6. **RT_STRING vs RT_HTML**：名称在 RT_STRING；信息卡优先 RT_HTML，缺失时回退 RT_STRING（可能仍是 RDL XML）。
7. **universe.ini pos vs multiuniverse.ini 坐标**：前者 MOD 未维护（35 个星系挤在同格），**导航图布局以 multiuniverse.ini 为准**。
8. **基础文件 vs `*mp`/`*sp`**：单机用基础文件（与 `*sp` 内容一致），在线服务器用 `*mp` 变体。
9. **CF41 vs CF103**：同一「蜂巢」的早期/后期副本（133 个物体坐标一致），保留终章使用的 `CF103`。
10. **St03b vs St03b2**：戴森球城市 vs 戴森球核心（内容不同），两者均保留。
11. **FP7_system vs FP7_systemmp**：前者是 M01A 被摧毁的剧情版，后者是自由模式版；保留 `FP7_systemmp`。
12. **FLCompanion 网格 vs 游戏网格**：FLCompanion 标注 A–I/1–9，游戏实际为 **A–H/1–8**；一律以游戏内截图为准。
