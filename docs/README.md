## 快速开始

1. 双击 `..\map\index.html` 使用地图（file:// 直接可用）。
2. 重新生成数据：`python ..\map\tools\extract_map.py`。
3. 先读 `00_工程文档.md`；查词用 `01`；改数据格式看 `02`；遇问题先查 `03`。

## 维护规范（摘要，全文见 00 文档 §7）

- 改版前先备份（**逐个复制内容**到 `backup_日期\`，禁止把目录复制进自身子目录——曾导致递归卡死，见 `03` P-11）。
- 新增内容先查重合并，不建平行文档；过期结论就地更正并标注日期。
- 结论冲突时以 `00_工程文档.md` §5 的决策表为准。
