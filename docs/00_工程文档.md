# 00 工程文档

> 自由枪骑兵 Crossfire 2.0.1（单机）互动式星系地图
> 本地游戏目录：`..\Freelancer Crossfire\`　地图本体：`..\map\`

## 1. 项目目标与成果

读取游戏内的星系清单与地图文件，生成一个**离线可用的 HTML 互动星系地图**，还原游戏内导航图的表现：

- **大地图**：5 个星区合并展示（Canis 右上 / Sol 右 / 内核中 / Altair 左 / Sirius 左下），352 条跳跃连接
- **星系图**：按游戏坐标绘制恒星、行星、基地、空间站、跳跃门/洞、小行星带/星云，含游戏同款 8×8 网格（A–H / 1–8）
- **详情卡**：物体名称、阵营、基地设施、游戏内信息卡全文（RDL → HTML）
- 搜索、图层筛选、「剧情/变体星系」开关、深浅一致的暗色 UI

## 2. 版本与范围（重要）

| 项 | 结论 |
|---|---|
| 游戏版本 | Crossfire Mod **2.0.1 Client Edition** |
| 模式 | **单机（SP）**，剧情通关后的自由模式为最终状态 |
| 权威来源 | 只信本机游戏文件 + 游戏内实测；**不依赖第三方工具**（FLCompanion 已证实有网格标注错误） |
| 排除内容 | 在线（MP）服务器数据、任务阶段变体星系（见 §5） |

## 4. 快速开始与使用说明

**使用**：双击 `map\index.html`（file:// 直接可用，无需服务器）。

### 大地图（宇宙视图）

- 5 个星区按官方银河图排列：Canis 右上、Sol 右、内核中、Altair 左、Sirius 左下。
- 节点＝星系，颜色＝星区（天狼星蓝/内核紫/Altair 橙/Canis 绿/Sol 红），大小≈物体数量。
- 连线：实线＝跳跃门、虚线＝跳跃洞、紫色点线＝随机跳跃洞。
- 橙色圆圈＝游戏内无导航图星系；房子名（自由联盟/库萨里/莱茵兰/布列塔尼亚）为水印。
- 单击节点看信息，双击节点（或「进入星系图」）进入星系内部。

### 星系图（行星系）

- 坐标与游戏一致（x 右、z 下）；网格 8×8（列 A–H、行 1–8），底部显示星系名。
- 图标：恒星（带色光晕）、行星（灰蓝圆）、基地（绿方块，可停靠）、空间站（菱形）、跳跃门（绿圆环）、跳跃洞（橙旋涡）、停靠环/武器平台/卫星等。
- **贸易航线**：按 `prev_ring/next_ring` 链还原的浅蓝折线（可点击查看终点与航段）。
- 区域：星云（紫）、小行星带（灰黄）、冰晶带（蓝）、碎屑带（灰）、雷区（橙）、熔岩（红）、气体（绿）。
- 单击物体 → 详情卡：类型、阵营、坐标、游戏内信息卡全文；基地附阵营、设施（酒吧/商品商/飞船商/装备商…）与**出售/收购清单（商品、装备、飞船）**。
- **物品卡片**：点击基地卡片中的商品/装备/飞船标签，打开其信息卡与出售/收购基地列表（可跳转）。
- 跳跃门/洞详情显示「通向」目标星系，可直接跳转。

### 操作

| 操作 | 效果 |
|---|---|
| 拖动 / 滚轮 | 平移 / 以鼠标为中心缩放 |
| 右下 ＋ / － / ⛶ | 放大 / 缩小 / 适应窗口 |
| 单击 / 双击 | 选择并打开信息面板 / 进入星系 |
| Esc | 星系图→大地图；再按关闭面板 |
| 搜索框 | 搜索星系或基地，直达 |
| 顶部开关 | 「剧情/变体星系」显示被排除的变体；「名称标签」开关标签 |
| 左侧筛选条 | 控制星系图内各类物体、贸易航线与区域显示 |

### 构建与校验

1. 重新生成数据：`python map\tools\extract_map.py`（读取游戏目录，重写 `map\data\`）。
2. 校验：查看 `map\data\extract_report.txt`（当前 0 解析失败、0 悬空连接）。

## 5. 关键决策摘要（依据详见 `03_解决方案文档.md`）

| 决策 | 结论 | 依据 |
|---|---|---|
| 单机/在线 | 采用单机基础系统文件 + `universe.ini` | `freelancer.ini`、`openspm13.ini` |
| 大地图布局 | 采用 `multiuniverse.ini` 星区坐标 | `universe.ini` 的 `pos` 有 35 个星系挤在同格 |
| 星区相对位置 | 官方银河图放射布局 | `reference\官方银河图.jpg` |
| 星系图方向 | x 右、z 下 | 游戏内纽约导航图截图（5 个跳跃门格子逐一吻合） |
| 网格 | 8×8，列 A–H、行 1–8，标签在格心 | 同上截图 |
| 任务变体 | 排除 17 个变体 + 1 个剧情专用，保留 162 个正式版 | 终章后 `openspm13.ini` 只解锁普通版门 |
| 信息卡 | Resources.dll(index 0) + RT_STRING 回退 + 原型回退 + RDL 解析 | DLL 实测 |
